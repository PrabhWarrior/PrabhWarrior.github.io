# Prabhkirat Singh, portfolio

A static site: plain HTML, CSS and a little JavaScript. There is no build step.

Live at https://prabhwarrior.github.io

## Files

- `index.html` – the whole site
- `styles.css` – all styling, with light and dark themes
- `site.js` – theme toggle, hero animation, count-up metrics and scroll reveal

## Preview locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Hosted on GitHub Pages from the `main` branch. Every `git push` redeploys the site.
